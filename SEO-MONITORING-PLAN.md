# Website Builders BD — Search Console monitoring plan

Last reviewed: 22 November 2026

The sitemap submission and initial URL indexing requests are not ranking results. Use Search Console data to measure what Google actually shows and which queries produce clicks.

## Weekly check

1. Open https://search.google.com/search-console/ and select the verified websitebuildersbd.shop property.
2. Open Performance → Search results.
3. Set the date range to the last 28 days. After a longer history is available, also compare the last 3 months with the previous period.
4. Review Total clicks, Total impressions, Average CTR, and Average position.
5. Open Queries. Separate branded queries (Website Builders BD / websitebuildersbd) from non-branded service queries.
6. Open Pages and check which URLs receive impressions and clicks.
7. Where available, filter by Country = Bangladesh and compare Mobile versus Desktop.
8. Export the report monthly and keep a dated copy.

## How to interpret the report

- Impressions: how often a search result for the site was shown.
- Clicks: how often people clicked through from Google.
- CTR: clicks divided by impressions.
- Average position: the average topmost position across impressions, not a fixed rank for every search.

Focus on useful trends in impressions and clicks, query relevance, and page performance. Do not judge progress from one manual Google search: results can vary by location, device, and personalization.
